# Real-time Analytics Dashboard on Cloud

## Project Overview
A cloud-based e-commerce application that collects customer order data, processes it using AWS services, and displays the processed data through an analytics dashboard.

## Architecture
Customer → API Gateway → Lambda → S3 → EventBridge → Lambda → DynamoDB → Analytics Dashboard

## AWS Services
- Amazon EC2
- Amazon API Gateway
- AWS Lambda
- Amazon S3
- Amazon EventBridge
- Amazon DynamoDB
- AWS IAM
- AWS CloudFormation

## Infrastructure as Code
The AWS infrastructure is created and managed using AWS CloudFormation.

## Project Objective
To build a cloud-based real-time analytics system for processing and analyzing e-commerce order data.
